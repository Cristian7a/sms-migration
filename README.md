# Proyecto SMS

## Descripción

Este proyecto es la migración de PHP a Python del proyecto SMS, el cual se encuentra en el repositorio [sms] (https://github.com/daviduwu-png/proyecto-sms/tree/main).

## Tecnologías

- Python
- Flask
- MySQL

## Estructura de carpetas

Aquí está la estructura completa de la carpeta `sms_migration` incluyendo subcarpetas y archivos:

```
sms_migration/
├─ .env.example
├─ README.md
├─ api/
│  ├─ README.md
│  └─ src/
│     ├─ app.py
│     ├─ config.py
│     ├─ run.py
│     ├─ dtos/                
│     ├─ models/
│     │  └─ rep_model.py
│     ├─ routes/              
│     ├─ services/
│     │  └─ example_service.py
│     └─ utils/               
└─ client/
	├─ README.md
	├─ public/
	│  ├─ index.html
	│  ├─ main.js
	│  └─ assets/              
	└─ src/
		└─ modules/
			└─ module-example/
				├─ module-example.html
				├─ module-example.js
				└─ README.md

```
